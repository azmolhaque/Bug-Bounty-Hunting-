# google-frontend.txt — what a Google-operated web host answers to.
# For acq-paths.sh via PATHS_FILE.
#
# Written for connected.google.com and express.cloud.google.com, two TIER0
# hosts added to the tier file on 2026-10-28, both answering 404 with Google's
# standard 1561-byte page at "/". A clean 404 baseline is the best case for a
# differential: anything that is not that page exists in some form.
#
# The signal to watch for is not 200. On these hosts a path that really exists
# and sits behind sign-in answers 302 to accounts.google.com, and a path behind
# Cloud IAP answers 302 with a GSE server header and the "Sign in - Google
# Accounts" page. Either tells you the route is real, which a 404 does not.
