## What was measured

### intrinsic.ai (Alphabet robotics), TIER1/TIER2, new today

30 hosts, 22 live. Flowstate in three environments, a developer community app,
an edge gateway, a marketing site.

* 30 content-matched software probes × 22 hosts, progress file 22/22 →
  **0 identified**. No Metabase, no Jenkins, no exposed `.git` or `.env`.
* `/healthz` answers 200 with 7 bytes on four hosts. § 3 drops health
  endpoints by name.
* The production bundle names `kubernetes-dashboard.intrinsic.ai` and
  `ipc.intrinsic.ai` — both **NXDOMAIN**. Internal names in a public bundle,
  nothing reachable.
* `support.intrinsic.ai` is a Freshdesk CNAME with an account-specific label:
  a precondition, not a takeover.
* 4.9 MB of production bundle holds no gRPC service names and no own-origin
  API. Every network path in it belongs to the Firebase SDK.

**The Firebase angle is closed by scope, permanently.** `googleapis.com`,
`appspot.com` and `sandbox.googleapis.com` are TIER4 in Google's own file, so
`identitytoolkit.googleapis.com`, `securetoken.googleapis.com` and the three
`intrinsic-accounts-*.appspot.com` projects cannot be probed at all. The clean
read-only test for whether sign-up is open was about to be run and was not.
Do not re-try this.

### The propagating estate, 352 hosts, almost all unseen before today

`propagate_tier_to_direct_subdomains` is set on 31 domains. Their direct
subdomains are not in the protobuf — they exist only in certificate logs — so
until `prop-subs.sh` was written they were in scope and invisible. 352 hosts,
217 live. Verily's Debug Project at eight sites across dev, preprod and
production: `insectary`, `cages`, `pupae`, `sorter`, `trough`, `hvac`, `bms`,
`surveillance`, `vehicle-1`…`vehicle-99`, `guacamole`, `unifi`,
`db-replica-of-onprem`.

* **IAP gap: 36 hosts (one per service name) × 14 paths = 504 requests,
  0 past the proxy.** Everything returns Google's login page, including
  `/healthz`, `/metrics`, `/_ah/health`.
* **135 dead hosts: 85 HAS-IP, 36 NO-RECORD, 14 NXDOMAIN, 0 dangling.**
* `aem-dev.debug.com` / `aem-stage.debug.com`: 21 AEM paths, 0 differed from
  Google's 404. The name says AEM; nothing is behind it.
* `count.debugproject.com` is the project's public counter page.
* The 38 `cameyo.com` hosts titled "default" are **one wildcard page on
  Google's own load balancer** — `jenkins.cameyo.com` is not Jenkins,
  `wazuh.cameyo.com` is not Wazuh, and a made-up name gets the same bytes.

**The one thing that looked like a finding:** every Cameyo application host
sends `X-Frame-Options: DENY` alongside
`frame-ancestors 'self' *.cameyo.com https://cameyo.com:* https://*.ninjaexcel.com`,
and browsers honour `frame-ancestors` over XFO. But RDAP says ninjaexcel.com
is six years old, paid through 2028, transfer-locked and actively served — a
customer embedding the product. Without control of a subdomain there we hold a
precondition, and that domain belongs to someone who never agreed to be
tested. Dropped.

## Instrument defects found, all of which had already printed a wrong line

1. **`spa-map.sh` printed "served from" above its own host's row**, so the
   output read as *production being served the development app*. That is a
   finding, and it was false. A line attached to the wrong row is worse than
   no line.
2. **`spa-map.sh` resolved relative assets against the origin root.**
   Production ships `src="main.js"` and redirects `/`, so its bundle was never
   fetched and the host was recorded as shipping nothing.
3. **`spa-map.sh` fetched assets without `-L`**, stopped at a 301, wrote
   nginx's 162-byte redirect page to disk as `asset-*.js`, read it as
   JavaScript and reported two hosts with zero of everything.
4. **`spa-map.sh` matched bare `.local` / `.internal`**, so `this.local`,
   `e.internal` and `window.local` were reported as internal hostnames —
   thirty of forty-four lines. Left alone, somebody reports those as a leak.
5. **`prop-subs.sh` dropped the apex** of a domain with no certificates, so
   `intrinsic.dev` was never probed.
6. **`prop-subs.sh` printed "8 names seen, 9 direct"** — more kept than read.
   Harmless cause, and a table that does not agree with itself stops being
   read.

Also: the self-test comparison was locale-dependent and passed in a container
while failing on the Pi, which is why `LC_ALL=C` is now set for the whole
script — two machines must write the same bundle the same way or tomorrow's
diff is noise.
